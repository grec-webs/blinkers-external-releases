# Blinkers Hub releases

Official Windows x64 release downloads and the signed automatic-update manifest.

Install **BlinkersHubSetup.exe** from the [Windows download page](https://blinkershub.com/download.html). Setup installs the app under your Windows account and adds Blinkers Hub to Start.

Version 0.21.5 restores the full custom HUD on supported Roblox 0.748: health, moves and cooldowns, ultimate state and effects, evasives, M1/combo counters, game chat, player list, fight history, compact live ping and session progress. Layouts, media integrations and music reactions remain included. ESP and camera lock remain removed. Unknown Roblox builds use a limited player-log fallback until compatibility is updated. Public relay multiplayer is not enabled.

From 0.21.5, Blinkers Hub checks for updates on startup and during play. You can finish a running session and install later. On the next launch, choose Install or exit the app. If you use 0.21.4, finish your session and run the website installer once to switch to these prompts.

Setup is per user. Blinkers Hub verifies the signed release and checks the downloaded executable before installing it. Windows may display “Unknown publisher.” A linked Discord account, device verification and launch reporting are required to use the client.
