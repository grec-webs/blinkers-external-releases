# Blinkers Hub releases

Official Windows x64 release downloads and the signed automatic-update manifest.

Install **BlinkersHubSetup.exe** from the [Windows download page](https://blinkershub.com/download.html). Setup installs the app under your Windows account and adds Blinkers Hub to Start.

The Windows companion uses Roblox's player log to recognize a TSB session. The public edition provides session timing, layout controls and supported desktop media integrations. See the download page for the current feature set.

The app verifies each update with a built-in publisher key and checks the downloaded executable's digest before replacement. Signed updates are mandatory. Setup is per user. The direct installer uses project signing, so Windows may display “Unknown publisher.” Access requires device verification. Launch reporting is optional.

This repository contains release files and public metadata. Signing keys and private chat configuration must never be committed here.
