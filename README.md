# Blinkers Hub releases

Official Windows x64 release downloads and the signed automatic-update manifest.

Install **BlinkersHubSetup.exe** from the [Windows download page](https://blinkershub.com/download.html). Setup installs the app under your Windows account and adds Blinkers Hub to Start.

The app verifies updates with a built-in publisher key. New releases are mandatory. Roblox itself does not need to close during an external update. Only explicitly supported Roblox builds can connect.

This repository contains release files and public metadata. Signing keys and private chat configuration must never be committed here.
